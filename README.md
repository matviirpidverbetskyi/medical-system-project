# Система обліку хвороб пацієнтів

Цей проєкт є системою медичних карток, яка дозволяє зберігати історію хвороб, рецепти та інформацію про лікарів.

## Технологічний стек
- **Мова:** Python 3.12+
- **Фреймворк:** Django 5.x
- **Менеджер пакетів:** uv
- **База даних:** SQLite (для розробки)

## Як запустити проєкт локально

### 1. Попередні вимоги
Переконайтеся, що у вас встановлено менеджер пакетів `uv`. Якщо ні, встановіть його:
- **Windows:** `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
- **macOS/Linux:** `curl -LsSf https://astral.sh/uv/install.sh | sh`

### 2. Клонування проєкту та встановлення залежностей
```bash
git clone <url-вашого-репозиторію>
cd <назва-папки>
uv sync
